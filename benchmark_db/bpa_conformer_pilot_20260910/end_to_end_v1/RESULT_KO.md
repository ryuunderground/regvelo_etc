# BPA 전용 컨포머–도킹 보정: 실제 실행 결과

2026-09-10. **도킹 → 원래 컨포머와의 연결 → 보정층 학습 → 시험 수용체 평가 → BPA 재추론까지 완료했다. 현재 모델의 채택은 보류한다.**

연결 방식은 구현됐고 실제 가중치도 학습됐다. 그러나 평균 도킹 점수 손해 감소와 달리 최선 컨포머 일치율은 나빠졌으며, BPA 진단에서도 개선되지 않았다. 일부 학습 실행은 손실 자체가 불안정했다. 따라서 이 결과는 전략 전체가 불가능하다는 증명도, 정확도가 개선됐다는 증명도 아니다.

## 1. 실제로 돌린 범위

32종 × 원래 seed42 컨포머 4개(0, 1, 10, 11) × 수용체 6개 = **768개 도킹 입력**이다. 20개 전체 컨포머도 내보내 검증했지만, 첫 도킹 파일럿에는 사전 계획의 제한 규모를 사용했다. 이후 BPA 재추론에는 원래 20개 전부를 사용했다.

| 수용체 | 공결정 | 입력 | 점수 사용 가능 | NO_POSE | 최종 자세 |
|---|---|---:|---:|---:|---:|
| ESRRG | 2E2R | 128 | 31 | 97 | 72 |
| ESR1 | 1GWR | 128 | 54 | 74 | 146 |
| ESR2 | 3OLL | 128 | 54 | 74 | 151 |
| AR | 2AM9 | 128 | 44 | 84 | 123 |
| PXR / NR1I2 | 4X1F | 128 | 108 | 20 | 315 |
| VDR | 7QPP | 128 | 92 | 36 | 249 |
| 합계 | 6개 | 768 | **383** | **385** | **1,056** |

Glide SP의 rigid 모드로 분자의 내부 모양을 고정하고, 위치·방향을 탐색했다. LigPrep, 사전 최소화, post-docking 최소화, Epik 보정은 적용하지 않았다. 원래 RDKit 화학 상태에 조건부인 시험이며, 생리적 양성자화 상태 전체를 탐색한 결과는 아니다.

1,056개 최종 자세 모두 전체 화학구조 대응과 내부 모양 검사를 통과했다. 반사를 허용하지 않는 정렬 RMSD의 최댓값은 **0.00005475 Å**로, 미리 정한 0.005 Å보다 작았다. 위치·방향의 차이를 내부 모양 변화로 오해하지 않았다.

점수는 각 입력의 최종 자세 중 SP Emodel이 가장 낮은 자세를 고른 뒤, 그 자세의 정밀한 docking score를 사용했다. `NO_POSE` 385개는 **결합 음성이 아니라 평가 불가**로 남겼다. 수용체 간 절대 도킹 점수를 실제 결합 순위 정답으로 섞지 않았다.

PGR 1A28은 같은 구조의 기존 포켓 임베딩이 없어 제외했다. 사용한 여섯 포켓은 원래 holo 구조 정체성이 일치하지만, 원래 임베딩 좌표와 단백질 준비 후 좌표가 원자별로 완전히 같다는 보증은 아니다.

## 2. 무엇을 학습했나

원래 DrugCLIP의 여섯 encoder와 임베딩은 고정했다. 분자 특징과 포켓 특징을 함께 받아 컨포머 점수를 보정하는 **공유 rank-4 보정층, 학습 파라미터 6,148개**만 새로 학습했다. 원자 거리 Gaussian이나 원래 encoder 가중치를 바꾼 실험은 아니다.

같은 물질·같은 입체상태·같은 포켓에서 성공한 컨포머들의 점수로 참고 분포를 만들고, 학생 분포가 이를 따르도록 KL 손실을 사용했다. 온도는 1, Adam 학습률은 0.01, weight decay는 0.01, 학습은 고정 200 steps였다. receptor ID나 conformer ID를 특징으로 넣지 않았다.

- 비교 가능한 컨포머가 2개 미만인 98개 상태 묶음은 제외했다.
- 남은 106개 상태 묶음 중 23개 보호 쌍은 학습에 넣지 않았다.
- 학습 가능한 83개 상태 묶음은 77개 물질–수용체 쌍에 해당한다. 같은 물질이나 수용체를 공유하므로 완전히 독립인 실험 77개라는 뜻은 아니다.
- BADGE/CBDO의 서로 다른 입체상태는 분리했다. 컨포머와 입체이성질체를 혼합하지 않았다.
- 모든 reference/Gold 보호 쌍과 BPA의 여섯 수용체 쌍은 학습에서 제외했다. 기존 Gold 라벨·분할·NO-GO는 바꾸지 않았다.
- 각 수용체를 통째로 빼놓는 LOTO 시험, 학습 seed 0/1/2, 교사 순서를 섞은 재학습 대조군을 실행했다. 총 **42개 실제 checkpoint**가 저장됐다.

현재 적격 Gold 개발 쌍이 없으므로 **실제 결합 정답에 대한 손실은 사용하지 않았다.** 이번에 학습한 것은 도킹 모양 선호의 모방이지 결합 분류기가 아니다.

## 3. 학습 전후 결과

아래는 시험 수용체의 77개 물질–수용체 쌍에서, 3개 학습 seed를 모두 포함한 평균이다. 도킹 점수 손해는 '선택한 컨포머 점수 − 해당 묶음의 최선 점수'로, 작을수록 좋다. 일치율은 수치 동률을 나눠 계산했다.

| 방법 | 도킹 점수 손해 ↓ | 최선 컨포머 일치율 ↑ | Kendall 순위 일치도 ↑ | 교사 분포 KL ↓ |
|---|---:|---:|---:|---:|
| 균등 무작위 선택의 기대값 | 0.3407 | 29.65% | — | — |
| 원래 DrugCLIP cosine | 0.3321 | **35.71%** | **0.0484** | **0.0535** |
| 실제 교사로 학습한 보정층 | **0.3014** | 32.03% | 0.0375 | 0.0823 |
| 교사 순서를 섞어 학습한 대조군 | 0.3228 | 30.74% | 0.0178 | 0.0957 |

평균 점수 손해는 약 9.24% 줄었지만, 이것을 정확도 9.24% 향상으로 부르면 안 된다. 최선 모양 일치율은 35.71%에서 32.03%로 내려갔고 순위·분포 지표도 악화했다. 교사 학습 모델의 seed별 손해는 0.2550 / 0.3169 / 0.3324로, 모든 seed가 개선된 것도 아니다.

보호된 23쌍의 별도 진단에서는 원래 손해 0.3853이 보정 후 평균 0.3978로 커졌다. 이 진단에서는 셔플 대조군이 오히려 더 좋았다. 보호 쌍은 이미 앞선 작업에서 살펴본 자료라 새로운 확증 시험 세트로 주장하지 않는다.

학습 자체의 문제도 있었다. 실제 교사 VDR-holdout/seed1의 기록 손실은 0.0487 → 1.1710으로 증가했고, 셔플 NR1I2-holdout/seed2도 증가했다. 반면 전체 비보호 자료로 재학습한 세 모델은 0.0511 → 0.0178 / 0.0212 / 0.0234로 감소했다. 나쁜 실행을 지우거나 가장 좋은 seed만 골라 보고하지 않았다. 따라서 학습 안정화 전에는 이 비교를 강한 방법론 결론으로 삼을 수 없다.

## 4. BPA 전용으로 보면

시험에 남은 BPA 여섯 쌍의 조건부 도킹 점수 손해는 **원래 0.3016 → 보정 후 평균 0.5522**였다. 실제 결합 정확도가 나빠졌다는 뜻은 아니지만, 이번 설정이 BPA의 교사 선호를 더 잘 모방했다는 근거는 없다.

ESRRG의 구체적인 예도 확인했다. 성공한 BPA 1번/10번 모양의 교사 참고 비중은 약 **80.5% / 19.5%**였다. 그러나 학생의 1번 비중은 세 seed에서 **50.9% / 48.4% / 51.0%**로 거의 절반에 머물렀다. 이 수치는 두 성공 모양에 한정한 조건부 비중이며 결합 확률이 아니다.

실제 사용 상황에 가까운 별도 추론에서는 **도킹 성공 여부를 보지 않고 BPA 컨포머 20개 모두**에 가중치를 주었다. 그 가중치로 원래 cosine을 평균한 여섯 포켓의 순서는 세 seed 모두 다음과 같았다.

`ESRRG → ESR2 → ESR1 → AR → PXR → VDR`

**원래 모델도 같은 순서였다.** 이 여섯 포켓 사이에서는 ESRRG가 학습 전부터 1위였으며, 이번 보정으로 1위에 올린 결과가 아니다. 전체 인간 pocketome 검색 순위로 확대 해석하면 안 된다. 학습 후 20개 가중치도 거의 균등했고, 가중 평균 점수 변화는 최대 약 0.000095였다.

## 5. 현재 판정과 다음 수정 순서

판정은 **실행 연결 성공 / 현 모델 채택 보류 / 실제 결합 정확도 개선 미검증**이다.

1. **학습 안정성부터 고친다.** 별도의 개발 규칙에서 학습률·훈련 손실 기준 checkpoint 정책을 정하고, 같은 불안정 실행을 그대로 비교하지 않도록 한다. 이번 시험 결과를 보고 좋은 seed만 선택하지 않는다.
2. **교사 점수의 안정성을 확인한다.** 동일 내부 모양의 초기 방향·독립 탐색 반복과 가까운 컨포머의 점수 변동을 측정하고, 불확실한 차이는 낮게 반영한다. 이번 BPA 1번/10번은 내부 RMSD 0.0196 Å인데 점수 차이가 1.419였다. 탐색·자세 선택 잡음 가능성은 있지만 미세 구조 차이의 효과를 배제한 결과는 아니다.
3. **학생이 구별할 수 있는 정보를 확인한다.** 거리만 입력하는 DrugCLIP은 정확한 반사 관계를 구별하지 못한다. 분자 내부 Gaussian의 가중치만 바꿔서는 없는 정보가 생기지 않는다. 필요하면 회전·이동·원자 순서에 적절히 불변인 추가 구조 특징을 별도 검증해야 한다.
4. **실제 결합쌍 학습·검증을 별도로 확보한다.** 어느 포켓에서든 후보 모양 중 상대적 1등은 생긴다. 그것만으로 그 수용체에 실제 결합한다는 정답은 되지 않는다. 적격 실험 결합 자료 없이는 BPA 수용체 발견 성능 향상이나 기존 Gold NO-GO 해제를 판단할 수 없다.

이 수정안은 후속 제안이다. 이번 결과를 본 뒤 추가 모델을 골라 성능이 좋아진 것처럼 제시하지 않았다.

입력 생성·수집·학습·분할 관련 테스트 **57개를 통과**했다. 독립 검토에서 42개 모델 모두 실제 파라미터 갱신, 보호 쌍 배제, 해당 LOTO 수용체 배제와 점수 재계산을 확인했다. 별도 실물 감사에서도 11,613개 검사와 95개 파일 해시 확인을 통과했다. 원본 보존 검증은 사용 파일의 고정 해시 범위이며 프로젝트 전체가 다른 사용자 작업으로 바뀌지 않았다는 주장은 아니다.

주 실행 코드는 `scripts/`의 `build_rigid_pilot_inputs.py`, `run_rigid_glide_local_pilot.py`, `collect_rigid_panel.py`, `merge_rigid_teacher.py`, `train_rigid_conformer_adapter.py`, `apply_bpa_adapter_diagnostic.py`다. 각 스크립트는 새 출력 위치를 요구하며 기존 결과를 덮어쓰지 않는다. Schrödinger 실행과 구조 읽기는 해당 라이선스 서버 연결이 필요하다.

초기 공유 폴더 작업의 ESRRG/ESR1 완료 결과는 보존했고 ESR2 시작 단계는 중단했다. 같은 입력을 로컬 임시 폴더로 옮긴 뒤 여섯 수용체를 모두 순차 재실행한 결과만 주 학습에 사용했다. ESRRG의 기존 성공 점수 31개는 재실행과 정확히 같았다. 여섯 로컬 엔진 실행 시간 합계는 약 179초이며, 입력 복사·검증·보관·학습 시간은 별도다. 감사용 임시 폴더는 완료 JSON에 경로를 남기고 보존했다.
